# 正确性检查流程

对于每一个重要推导：

1. 首先完整记录老师板书中的推导。

2. 然后检查：

- 每一步数学变形是否成立。
- 使用的公式、定理是否适用。
- 前后符号是否一致。
- 最终结果是否与前面条件一致。

3. 如果推导正确：

不需要额外说明。

4. 如果发现疑似问题：

必须保留原推导，并添加 Obsidian 注释。

格式：

> [!warning]
> **板书检查提醒**
>
> 位置：
> x
>
> 板书内容：
> （引用原内容）
>
> 检查结果：
> 此处可能存在 XXX 问题。
>
> 说明：
> 根据 XXX 定理/公式，此处通常应为 XXX。
>
> 注意：
> 以上为检查提示，未修改原板书内容。

$$


> [!warning]

>
> $$

> $$

> 但保留原板书内容，不自动修改。
